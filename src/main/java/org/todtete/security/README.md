# Security

## Overview

This package explores security improvements introduced
or advanced in Java 27.

## Post-Quantum Hybrid Key Exchange

Java 27 includes support for hybrid key exchange algorithms
for TLS 1.3.

The approach combines a quantum-resistant algorithm with
a traditional algorithm.

## Java 27 Feature

**JEP 527 — Post-Quantum Hybrid Key Exchange for TLS 1.3**

## Why It Matters

The goal is to strengthen secure communications against
future quantum-computing threats while maintaining
compatibility with traditional cryptographic mechanisms.

## Important

This project does not implement cryptographic algorithms
manually.

The demonstration focuses on understanding the Java platform
capabilities and security architecture.
