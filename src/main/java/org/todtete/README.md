# Java 27 Feature Lab

This package contains the practical demonstrations included
in the Java 27 Feature Lab.

The project follows a **Before & After** methodology to
compare traditional Java approaches with selected capabilities
introduced or advanced in JDK 27.

## Feature Areas

| Area | Feature |
|------|---------|
| Pattern Matching | Primitive Types in Patterns |
| Concurrency | Structured Concurrency |
| Constants | Lazy Constants |
| Performance | G1 Default |
| Performance | Compact Object Headers |
| Security | Post-Quantum TLS |
| Vector Computing | Vector API |

## Project Philosophy

The objective is not simply to demonstrate new syntax.

Each example focuses on:

1. The problem.
2. The traditional solution.
3. The Java 27 approach.
4. The technical difference.
5. The practical relevance.
6. The maturity of the feature.
